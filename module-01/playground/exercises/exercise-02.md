# Exercise 2: Create, Copy, Rename, and Move Files

## Objective
Learn how to create, copy, rename, and move files.

## Commands

```bash
cd ~/bash-course/module-01/playground

touch idea.txt

cp idea.txt idea-copy.txt

mv idea-copy.txt plan.txt

mkdir drafts

mv plan.txt drafts/

ls
ls drafts
```

## Key Concepts

- `touch` creates an empty file.
- `cp` copies a file.
- `mv` can:
  - Rename a file.
  - Move a file into another directory.

## Challenge

Before running the final two `ls` commands, predict the output.
